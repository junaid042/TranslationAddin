
# 🌐 Email Translation Outlook Add-in

Email Translation Add-in is a powerful Outlook Add-in that enables users to translate emails instantly in both **read mode** and **compose mode**. It helps users communicate across languages seamlessly without leaving Outlook.

## ⚙️ How It Works

### 📖 Read Mode:
1. Open an email in Outlook  
2. Launch the Translation Add-in  
3. Select target language  
4. View translated email instantly  

### ✍️ Compose Mode:
1. Start composing a new email  
2. Enter your message  
3. Choose target language  
4. Click translate  
5. Replace or insert translated text  

---

### 5. Sideload Add-in into Outlook

* Open Outlook
* Go to Add-ins → Upload My Add-in
* Upload the manifest file
